# סינריון - מדריך מלא (WEB בלבד)

המערכת עובדת דרך ממשק WEB מקומי.

## מה המערכת עושה

- בדיקת PDF בלבד: בודקת שהמערכת מצליחה לקרוא את דוח ה-PDF.
- אימות מול סינריון: פותחת את אתר סינריון וממתינה להתחברות ידנית.
- דיווח אוטומטי לסינריון: קוראת PDF ומדווחת שעות בהתאם לדוח.

## דרישות

- Windows
- דפדפן Chrome או Edge
- גישה לסינריון

לא נדרש Python במחשב משתמש קצה.

## הפעלה למשתמש קצה

1. חלצי את הקובץ release/synerion_attendance.zip לתיקיה רגילה.
2. הפעילי את התחל-כאן.bat.
3. אם הדפדפן לא נפתח אוטומטית, היכנסי ידנית לכתובת http://127.0.0.1:5000.

## אתר סינריון

- ברירת המחדל היא prologic.
- לחברות קבלן שונות יש דומיין שונה בסינריון:
	- קומבלק: https://trex.synerioncloud.com/
	- פרולוגיק: https://prologic.synerioncloud.com/
- בקובץ synerion_site.txt שומרים רק את הקידומת שלפני synerioncloud.com.
- לדוגמה: prologic או trex.
- אם מדביקים URL מלא, המערכת שומרת ממנו רק את הקידומת.

## הסבר על כל קובץ בתיקיית ההפצה

התיקיה הרלוונטית:
release/synerion_attendance

- התחל-כאן.bat
	נקודת הכניסה למשתמש. זה הקובץ שאמור להפעיל.

- synerion_web_ui.exe
	מפעיל את שרת ה-WEB המקומי ואת המסך בדפדפן.

- synerion_attendance.exe
	מנוע העבודה שמבצע את הלוגיקה של בדיקה/אימות/דיווח מאחורי הקלעים.

- synerion_site.txt
	שומר את קידומת אתר סינריון הנבחרת, למשל prologic או trex, כדי שלא יהיה צורך להקליד שוב בכל הרצה.

- README.md
	המדריך המלא הנוכחי.

## למה יש גם EXE וגם BAT

- EXE הוא התוכנה עצמה.
- BAT הוא קיצור דרך שמפעיל את ה-EXE בצורה נוחה למשתמש.

במילים פשוטות: EXE הוא המנוע, BAT הוא כפתור ההפעלה.

## פתרון תקלות

- אם הדפדפן לא נפתח: לפתוח ידנית את http://127.0.0.1:5000.
- אם PDF לא נקרא: לוודא שזה דוח נוכחות תקין ממל"מ.
- אם סינריון שינה מסכים/כפתורים: ייתכן שיידרש עדכון בקוד.
