# אוטומציית דיווח נוכחות לסינריון

המטרה של הכלי היא לחסוך דיווח כפול בשתי מערכות.

תהליך העבודה:

1. מדווחים שעות במערכת מל"מ.
2. מפיקים דוח PDF ממל"מ.
3. מריצים את הכלי ובוחרים את ה־PDF.
4. הכלי מזין אוטומטית את שעות הנוכחות לסינריון.

ימי חופשה ומחלה עדיין ממולאים ידנית בתוך סינריון.

## גרסת הפצה למשתמש קצה

יש גם גרסה להפצה שאינה דורשת התקנת Python.

מה נדרש במחשב היעד:

- Windows
- דפדפן Chrome או Edge מותקן
- גישה לסינריון

מה לא נדרש במחשב היעד:

- Python
- התקנת חבילות
- הרצת `setup.bat`

הממשק המקומי ב-Web כלול בהפצה ופועל גם הוא בלי Python.

## למי זה מתאים

- משתמשי Windows
- דוברי עברית
- משתמשים לא טכניים שרוצים לעבוד בלחיצה כפולה על קובץ

## קבצים חשובים

- `02-בדיקת-קובץ-PDF.bat` - קובץ מומלץ למשתמש קצה לצורך בדיקת הדוח
- `03-אימות-מול-סינריון.bat` - קובץ מומלץ למשתמש קצה לצורך אימות בלבד
- `04-דיווח-אוטומטי-לסינריון.bat` - קובץ מומלץ למשתמש קצה לצורך הזנה אוטומטית
- `web_app.py` - ממשק Web מקומי בעברית להעלאת PDF והרצת המצבים
- `run_web.bat` - הפעלה מהירה של ממשק ה-Web המקומי
- `05-ממשק-ווב-מקומי.bat` - קיצור להפעלת הממשק המקומי
- `setup.bat` - התקנה חד-פעמית על כל מחשב
- `run_summary.bat` - בדיקת נתוני ה־PDF בלבד, בלי לפתוח את סינריון
- `run_verify.bat` - בדיקת התאמה בין הדוח לבין סינריון
- `run_auto.bat` - הזנה אוטומטית של שעות הנוכחות לסינריון

## התקנה ראשונית

למשתמש קצה אין צורך בהרצה של `setup.bat`.

עובדים ישירות מתוך חבילת ההפצה:

1. מחלצים את `release/synerion_attendance.zip` לתיקייה רגילה.
2. מפעילים את אחד מקבצי ההפעלה הממוספרים בעברית.

## שימוש יומיומי

### בדיקה בלבד

1. לוחצים פעמיים על `02-בדיקת-קובץ-PDF.bat`.
2. בוחרים את קובץ ה־PDF מהחלון שנפתח.
3. רואים סיכום שעות ובודקים שהנתונים תקינים.

### אימות מול סינריון

1. לוחצים פעמיים על `03-אימות-מול-סינריון.bat`.
2. בוחרים את קובץ ה־PDF.
3. מתחברים לסינריון בדפדפן אם מתבקשים.
4. הכלי מציג האם הסיכום בסינריון תואם לדוח.

### הזנה אוטומטית לסינריון

1. לוחצים פעמיים על `04-דיווח-אוטומטי-לסינריון.bat`.
2. בוחרים את קובץ ה־PDF.
3. מתחברים לסינריון בדפדפן אם מתבקשים.
4. הכלי מזין את שעות הכניסה והיציאה לפי הדוח.

### ממשק Web מקומי (חדש)

אפשר לעבוד גם דרך דף מקומי בדפדפן במקום חלון CMD.

1. מריצים `run_web.bat` (או `05-ממשק-ווב-מקומי.bat`).
2. נפתח דפדפן בכתובת `http://127.0.0.1:5000`.
3. בוחרים קובץ PDF.
4. לוחצים על אחד המצבים:
	- בדיקת PDF בלבד
	- אימות מול סינריון
	- דיווח אוטומטי לסינריון
5. רואים את הפלט ישירות בדף.

בהפצה למשתמש קצה, הממשק מופעל מ-EXE מקומי ולכן לא דורש Python.

## מה הכלי עושה ומה לא

- כן: קורא שעות נוכחות מקובץ PDF של מל"מ.
- כן: מזין שעות כניסה ויציאה לסינריון.
- לא: מזין ימי חופשה.
- לא: מזין ימי מחלה.
- לא: מחליף בדיקה אנושית לפני שמירה סופית.

## שיתוף עם משתמשים אחרים

כדי להפיץ למשתמשים לא טכניים:

1. שולחים רק את `release/synerion_attendance.zip`.
2. מבקשים מהמשתמש לחלץ את ה-ZIP לפני הרצה.
3. ממליצים להתחיל עם `05-ממשק-ווב-מקומי.bat` או `04-דיווח-אוטומטי-לסינריון.bat`.
4. אין צורך ב-Python ואין צורך ב-`setup.bat`.

## למשתמשים מתקדמים

אפשר גם להריץ דרך שורת פקודה עם נתיב PDF:

```powershell
python attend.py --summary-only --pdf "C:\path\to\report.pdf"
python attend.py --verify --pdf "C:\path\to\report.pdf"
python attend.py --auto --pdf "C:\path\to\report.pdf"
```

## פתרון תקלות

- אם חלון בחירת הקובץ נסגר בלי בחירה, פשוט להריץ שוב את קובץ ההפעלה.
- אם ה־PDF לא נקרא נכון, להתחיל מ־`run_summary.bat` ולבדוק את השורות שנשלפו.
- אם הדפדפן לא נפתח, לוודא שמותקן Chrome או Edge.
- אם סינריון שינה את המסך או הכפתורים, יהיה צורך לעדכן את `attend.py`.
